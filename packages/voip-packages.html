Choosing a Plan

Which VoIP Option Fits Best?

A quick guide to help clients choose the right starting point before requesting a formal quote.

Single user or low volume

Start with a VoIP Line – Usage Based if call volume is low and you prefer usage billing.

Small teams

Unlimited VoIP Line Premium is often better when a few devices or more inbound capacity are needed.

Businesses with PBX

Use SIP Trunks when connecting multiple numbers, channels or a hosted switchboard.

Need routing and extensions

Add Hosted Switchboard / Cloud PBX for IVR, ring groups, queues and extensions.

Use Cases

Which VoIP Package Is Right for You?

Match the package type to users, call volume, inbound capacity and whether a Cloud PBX is required.

Single user

Small office

Growing team

Questions

Frequently Asked Questions

Quick answers before you request a VoIP quote.

Do VoIP prices exclude VAT?

Yes. All VoIP monthly pricing is shown excluding VAT unless clearly stated otherwise.

Do I need internet for VoIP?

Yes. VoIP requires a stable internet connection and suitable network setup for reliable call quality.

Can I keep my existing number?

Number porting can be requested and is subject to provider approval and requirements.

Do I need a SIP Trunk for Hosted Switchboard?

Yes. Hosted Switchboard / Cloud PBX requires a VoIP SIP Trunk, charged separately.

Are phones included with VoIP plans?

No. Hardware, devices and accessories are quoted separately unless included in a written quote.

Can you help choose phones?

Yes. The Phone Catalogue includes Fanvil devices and a quote basket for device enquiries.
