# Future Creative Group Website

Official website source code for **Future Creative Group (Pty) Ltd**, a South African IT, security, networking, communications and digital solutions company.

## Overview

The project powers the Future Creative Group corporate website and its related customer-facing web services. It is built primarily with HTML, CSS and JavaScript and includes dedicated pages for services, packages, contact, downloads and the FCG customer portal.

## Technology

- HTML5
- CSS3
- JavaScript
- Responsive web design
- Server-side integrations where required

## Key Areas

- Corporate website and service catalogue
- IT, networking and infrastructure services
- CCTV, access control and security solutions
- VoIP, business email and cloud services
- Website design and digital solutions
- Customer portal
- Contact and support workflows

## Project Structure

```text
/
├── assets/          # CSS, JavaScript, images and shared assets
├── auth/             # Authentication-related pages and resources
├── contact/          # Contact and enquiry pages
├── downloads/        # Customer downloads and resources
├── fcgportal/        # Customer portal application
├── index.html        # Main website entry point
└── packages.html     # Service and package information
```
